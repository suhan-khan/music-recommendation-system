# Music Recommendation System

A simple music recommendation system built using Python and machine learning. It recommends songs similar to the song selected by the user.

## Tech Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit

## How It Works

The songs are converted into numerical features and compared using cosine similarity. The system then returns the songs most similar to the selected song.

## Run Locally

```bash
git clone <repository-link>
cd Music_Recommendation
pip install -r requirements.txt
streamlit run app.py
```
